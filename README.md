# MONO co-op сервер на Render.com

Готовий набір файлів, щоб підняти кооперативний сервер MONO на хостингу **Render** (безкоштовний тариф підходить). Друзі зможуть підключатися з інтернету — без "запусти node на моєму ПК".

## Що в папці

| Файл | Що це |
|---|---|
| `server.js` | WebSocket-сервер коопу (релай позицій, пострілів, кімнат). Протокол 1-в-1 як у клієнта гри |
| `package.json` | Залежності (`ws`) і команда старту `node server.js` |
| `render.yaml` | Blueprint Render — сервіс налаштовується автоматично |
| `index.html` | Ваша гра. Сервер віддає її на головній сторінці — друзі просто відкривають посилання і грають |
| `.gitignore` | Щоб `node_modules` не потрапив у git |

---

## Крок 1. Завантажити файли на GitHub

1. Зареєструйтесь на [github.com](https://github.com) (якщо ще немає акаунта).
2. Створіть новий **публічний** репозиторій, наприклад `mono-coop`.
3. Завантажте у нього **всі 5 файлів** з цієї папки (`server.js`, `package.json`, `render.yaml`, `index.html`, `.gitignore`). Через веб-інтерфейс: кнопка **Add file → Upload files**.

> `index.html` — це ваша гра (той самий файл, що ви надіслали). Якщо оновите гру — просто замініть файл у репозиторії, Render сам передеплоїть.

## Крок 2. Створити сервіс на Render

1. Зареєструйтесь на [render.com](https://render.com) (можна через Google/GitHub).
2. У дашборді: **New + → Web Service**.
3. Підключіть свій GitHub-репозиторій `mono-coop`.
4. Налаштування (якщо використовуєте `render.yaml`, більшість підставиться сама):

| Поле | Значення |
|---|---|
| Name | `mono-coop` (стане частиною адреси) |
| Region | будь-який, найближчий — Frankfurt |
| Runtime | **Node** |
| Build Command | `npm install` |
| Start Command | `node server.js` |
| Instance Type | **Free** |

5. Натисніть **Create Web Service** і зачекайте 1–2 хвилини, поки зʼявиться `Live`.

## Крок 3. Дізнатись адресу

Після деплою адреса буде внизу сторінки сервісу, у форматі:

```
https://mono-coop.onrender.com
```

Це водночас:
- **гра** — відкрийте в браузері і граєте;
- **кооп-сервер** — адреса WebSocket: `wss://mono-coop.onrender.com`.

## Крок 4. Грати в кооп

1. У грі: **CO-OP LOBBY** — гра **підключається автоматично** до `wss://theserver-e009.onrender.com` ще при завантаженні (статус стане `Connected`).
2. Хост: **CREATE ROOM** → зʼявиться код кімнати (6 символів). Надішліть його друзям.
3. Друзі: відкривають гру, заходять у **CO-OP LOBBY**, вводять код у **Room code** → **JOIN**.
4. Всі тиснуть **READY**, хост тисне **START (HOST)** — гра стартує у всіх одночасно, рух і постріли синхронізуються.

Якщо захочете інший сервер — можна вписати свою адресу в поле (тоді теж повністю з `wss://` на початку; якщо схему не вказати, гра сама додасть `wss://`, а для `localhost` — `ws://`).

- **Інтро повністю видалене** — гра одразу відкривається на головному меню. Кнопки REPLAY INTRO більше немає.

## Публікація на itch.io

Чорний екран на itch.io був через кінематографічне інтро: при першому запуску гра навмисно показує чорний екран із маленьким текстом, а картинки `res/title.PNG` на itch не було (вона не вбудована) — тож виглядало це як "все чорне й нічого не працює". Тепер інтро видалене, меню відкривається одразу.

Як правильно залити:

1. itch.io → Dashboard → **Upload new project**.
2. У полі **Kind of project** обери **HTML** (не Downloadable!).
3. Завантаж **mono-game.zip** (це zip, де лежить тільки `index.html` — я його вже зробив, файл поруч з цією папкою).
4. Постав галочку **This file will be played in the browser**.
5. Viewport: `1280 × 720`, увімкни **Fullscreen button**.
6. Save & view — гра відкриється одразу на меню.

> itch.io показує гру в iframe — pointer lock і звук працюють. Якщо колись побачиш червону рамку з текстом помилки — надішли мені цей текст, я виправлю.

## Нюанси безкоштовного тарифу Render

- Сервер **засинає після ~15 хвилин без підключень**. Перше підключення після сну "холодний старт" — до ~50 секунд, статус у лобі буде Connecting… просто зачекайте.
- Щоб сервер не засинав: на [uptimerobot.com](https://uptimerobot.com) (безкоштовно) зробіть Monitor → HTTP(s) на адресу `https://mono-coop.onrender.com/healthz` з інтервалом 5 хвилин.
- Ліміт безкоштовного тарифу — 750 годин роботи на місяць (вистачає з запасом).
- WebSocket на Render працює без додаткових налаштувань — keep-alive ping уже вшитий у `server.js`.

## Запуск локально (для перевірки)

```bash
npm install
npm start          # сервер на ws://127.0.0.1:8765
```

У лобі гри тоді вводите `ws://127.0.0.1:8765`.

## Якщо щось не працює

| Симптом | Причина / рішення |
|---|---|
| Connection error одразу | Не вказано `wss://`, або сервер ще деплоїться/заснув — зачекайте хвилину |
| Connecting… дуже довго | Холодний старт безкоштовного тарифу (до ~50 с) |
| Room not found | Хост ще не створив кімнату, або код з іншого сервера |
| Друзі не бачать гру за посиланням | Переконайтесь, що `index.html` закомітований у репозиторій і деплой `Live` |

## Технічні деталі сервера

- Релай повідомлень `pos` (12.5 Гц) і `shot` між гравцями кімнати, `id` і `name` додаються сервером — клієнт нічого змінювати не потребує.
- Кімнати — 6 символів без схожих знаків (0/O/1/I), регістр не важливий.
- Якщо хост вийшов — роль хоста автоматично переходить наступному гравцю в кімнаті.
- Порожня кімната видаляється, відвислі зʼєднання чистяться ping/pong кожні 30 с.

## Як залити гру на itch.io (щоб не було чорного екрана)

1. Вкладка **Distribute** → **Uploads** → **Upload files**.
2. Файл має бути **саме `index.html` з кореня** — якщо заливаєш ZIP, то `index.html` має лежати **в корені архіву**, а не всередині папки (ZIP всередині папки = itch не знаходить гру).
3. Після аплоаду постав галочку **This file will be played in the browser** (інакше itch покаже сторінку завантаження, а не гру).
4. **Save & view page** → кнопка **Run game**. Якщо браузер показує стару версію — жорстке оновлення (Ctrl+F5): itch кешує білди.
5. Якщо гра все одно не стартує: у новій версії index.html замість чорного екрана з'явиться **червоне табло з текстом помилки** — надішли його скріншот, і причину буде видно одразу.

## Що нового у грі (index v6)

- **Лоббі (ГРА ПО МЕРЕЖІ)**: нагорі статус, CONNECT, CREATE ROOM і велике поле **коду кімнати** з кнопкою ДОЄДНАТИСЯ; нижче — **НАЛАШТУВАННЯ ХОСТА**: карта / режим / тяжкість (діють для всіх гравців при START).
- **Тяжкість**: ЛЕГКО (вороги −25% HP, −50% шкоди, повільніші, менше в хвилі) / НОРМА / СЛОЖНО (+50% HP, +75% шкоди, швидші, +30% в хвилі). Вибір — на головному екрані та в лоббі, зберігається.
- **Мова**: НАЛАШТУВАННЯ → «Мова / Language / Язык» → English / Українська / Русский. Меню, налаштування, лоббі, керування — перекладені; вибір запам'ятовується.
- **Зброя**: у Пісочниці відкрита вся одразу; у Звичайному режимі дробовик відкривається бонусом (кожні 5 хвиль) або після босів.
- **Возродження в коопі**: якщо гравець загинув, а інші вижили — він **возроджується на початку наступної хвилі з 25 HP** (на екрані смерті напис «ВОЗРОЖДЕНИЕ НА СЛЕДУЮЩЕЙ ВОЛНЕ — 25 HP», у хвилю возродження гра сама повертає в бій). У сольній грі смерть як і раніше — кінець забігу.
- **Ники над головами**: кожен гравець на карті має світлу табличку з ніком над головою (видно всім, за стінами не видно).
- **Графіку покращено** (НАЛАШТУВАННЯ → розділ ГРАФІКА):
  - **Підтінок білого** — слайдер 0–360 + пресети ВИКЛ/ЗОЛОТИЙ/ЧЕРВОНИЙ/ЗЕЛЕНИЙ/БЛАКИТНИЙ/СИНІЙ/ПУРПУРНИЙ: весь білий в іграх стає обраним кольором. Фільтр **локальний** — змінює картинку тільки у того гравця, хто його вибрав, інших не чіпає.
  - **Масштаб рендера** — Низький / Середній / Високий / Ультра (для слабких ПК і телефонів).
  - **Туман** — легкий ефект глибини.
- Код кімнати можна вводити і **Enter-ом** (поле КОД КОМНАТИ + ПРИСОЕДИНИТЬСЯ).
- У `server.js` поле `diff` тепер проходить наскрізь при START. **Старий задеплоєний сервер продовжить працювати** — клієнт дублює тяжкість у полі `mode`, але якщо перезаллєш `server.js` на Render, все стане чистіше.

## Що нового у грі (index v7)

- **Гра разом з телефонів і ПК**: кооп повністю кросплатформний — один гравець заходить з браузера на компі (миша + клавіатура), інший з телефона (тач-кнопки). Тестовано: хост на ПК + гість в емуляції iPhone в одній кімнаті, бачать одне одного, старт синхронний. На телефоні з'явилась кнопка **LIGHT**.
- **Ліхтарик**: білий конус світла від гравця. Увімкнення: клавіша **F** (перепризначається в НАЛАШТУВАННЯ → КЛАВІШІ), кнопка **LIGHT** на телефоні, або галка **Ліхтарик/Фонарик** у НАЛАШТУВАННЯ → ГРАФІКА. Стан запам'ятовується.
- **Налаштування яскравості тепер діє і на ворогів** (крім боссів): звичайні вороги стають яскравішими/темнішими разом із повзунком Яскравість, а ліхтарик **додатково підсвічує ворогів у конусі** (до ~2× поруч попереду). Боси (СКОЛОПЕНДРА, ВІРУС) намальовані самоосвітленими і виглядають як і раніше.
- **Возродження виправлене до кінця**: поки гравець мертвий у коопі, його локальні вороги ніхто не вбиває — тому через ~10 с хвиля м'яко очищається («WAVE CLEARED») і наступна хвиля возроджує з 25 HP. Без цього возродження могло не настати взагалі.

## Що нового у грі (index v8) — СПІЛЬНІ ВОРОГИ

- **Спільні вороги в онлайні**: хост симулює бій для всієї кімнати. Усі бачать одних і тих самих ворогів (спавн, HP, смерть, боси, ВІРУС). Вбивства зараховуються тому, хто стріляв.
- **Вороги агряться на найближчого гравця** — біжать на того, хто ближче стоять, і бʼють саме його.
- **Гравці бачать один одного як білі циліндри з чорним контуром і ніком над головою.**
- **У коопі паузи більше немає взагалі**: Esc / втрата курсору / згортання вкладки НЕ зупиняють гру. Авто-пауза на компах прибрана.
- Помер, але хтось вижив → відродження на початку наступної хвилі з 25 HP (як і було). Вся команда мертва → усі повертаються в лобі.
- Вся зброя відкрита з самого початку (дробовик без замка).
- FIX крашу на старих браузерах/телефонах: `document.exitPointerLock` більше не ламає гру (помилка з вашого скріншота).

> **ВАЖЛИВО — перезалйте сервер!** Спільні вороги вимагають нового `server.js` (він ретранслює ігрові події `eny/espn/wsp/ehit/ekill/pdmg/...`).
> Без оновлення сервера кооп запуститься, але вороги у пірів зникнуть. Просто замініть `server.js` у репозиторії — Render сам передеплоїть.
